# Dashboard M3 Fondos Mutuos

Dashboard estático para visualizar información de fondos mutuos, prospección del modelo M3, snapshot del portafolio y backtesting.

## Uso

La aplicación está pensada para GitHub Pages.

1. Activa `Settings > Pages`.
2. Selecciona `Deploy from a branch`.
3. Usa la rama `main` y la carpeta `/root`.
4. Entra a `https://42571634-gif.github.io/modelo_predictivo_fondos_mutuos/`.
